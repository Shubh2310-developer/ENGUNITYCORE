\section{OmniRAG API Contract}
\label{sec:api-contract}

\subsection{Stream Endpoint}
\label{sec:stream-api}

\begin{verbatim}
POST /api/v1/omni-rag/stream
Content-Type: application/json
Authorization: Bearer <JWT>

Request body:
{
  "query":      string,          // Required. Natural language query.
  "session_id": string | null,   // Optional. Resumes an existing session.
  "strategy":   string | null,   // Optional. Overrides classifier:
                                 //   "direct_generation" | "graph_rag"
                                 //   | "recursive_intensive"
  "image_urls": [string],        // Optional. Public image URLs.
  "image_ids":  [string],        // Optional. Stored image IDs.
  "turbo_quant": {               // Optional. Inference optimization.
    "enabled":   boolean,
    "mode":      "auto"|"force"|"off",
    "bit_width": 2..8
  }
}

Response: text/event-stream (SSE)

Event types:
  { "type": "metadata", "complexity": "SINGLE_HOP", ... }
  { "type": "content",  "content": "..." }
  { "type": "done",     "strategy": "vector_rag",
    "documents": [...] }
  { "type": "error",    "message": "..." }
\end{verbatim}

\subsection{Research Endpoint}
\label{sec:research-api}

\begin{verbatim}
POST /api/v1/research/stream
Content-Type: application/json
Authorization: Bearer <JWT>

Request body:
{
  "query":               string,
  "depth":               "quick"|"standard"|"deep"|"exhaustive",
  "max_iterations":      integer (1-10),
  "include_web_search":  boolean,
  "include_graph_search":boolean,
  "output_format":       "detailed"|"summary"|"bullet_points"
}

Response: text/event-stream (SSE)

Event types:
  { "event_type": "status",       "progress_percent": float, ... }
  { "event_type": "sub_query",    "progress_percent": float, ... }
  { "event_type": "source_found", "progress_percent": float, ... }
  { "event_type": "complete",     "progress_percent": 100.0,
    "data": { "report": ResearchReport } }
\end{verbatim}

\section{Deployment Configuration Reference}
\label{sec:deployment}

The production deployment guide is documented in
\texttt{docs/deployment/DEPLOYMENT\_GUIDE\_STEP\_BY\_STEP.md}. The key
environment variables are:

\begin{verbatim}
SUPABASE_URL          — Supabase project URL
SUPABASE_SERVICE_KEY  — Service role key (never expose to client)
DATABASE_URL          — PostgreSQL connection string
MONGO_URI             — MongoDB Atlas or self-hosted URI
REDIS_URL             — Redis connection string
GROQ_API_KEY          — Groq inference API key
OPENAI_API_KEY        — OpenAI API key (optional, for GPT-4V)
BRAVE_SEARCH_API_KEY  — Brave Search API (WebSearchFallback)
ENABLE_TURBO_QUANT_CHAT — Feature flag for TurboQuant (default: false)
\end{verbatim}

\textbf{Security note:} Never commit the above secrets to version control.
The \texttt{.env.example.ai} file in \texttt{backend/} provides a safe
template with all keys listed and empty values.
