QUICK START - RUNNING TESTS
====================================================================

cd frontend

# Install Playwright browsers (first time only)
npx playwright install

# Run all tests
npx playwright test

# Run in UI mode (interactive)
npx playwright test --ui

# View test report
npx playwright show-report
